# 🧮 Simple Calculator

A modern, clean, and fully responsive web calculator built with HTML5, CSS3, and JavaScript. It supports standard arithmetic operations, decimal inputs, and complete keyboard navigation.

## ✨ Features

- **Clean UI & Responsive Design:** Styled with CSS Grid and modern color schemes for a sleek look.
- **Keyboard Support:** Type numbers, use operators, press `Enter` to calculate, `Backspace` to delete, and `Escape` to clear.
- **Error Handling:** Automatically catches invalid inputs or syntax errors and displays an error state gracefully.
- **Precision Management:** Limits long decimals to prevent UI overflow issues.

## 🚀 Built With

- **HTML5** - Structure and layout
- **CSS3** - Custom styling, Flexbox, and CSS Grid
- **JavaScript (ES6+)** - Core calculation logic, event listeners, and keyboard handling

## 📦 How to Use

1. Clone or download this repository.
2. Open `index.html` in any web browser.
3. Start calculating using either your mouse or your keyboard!
